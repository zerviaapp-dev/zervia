> **Reading the scale:** Weight fluctuates 1–2 kg daily from water, food, and hormones. Judge by the *trend across 2–3 weeks*, never by a single day.

## Measurements Log

Measure every 2 weeks (weeks 0, 2, 4, 6, 8). Use a soft tape measure, relaxed — don't suck in.

| Measurement | Wk 0 | Wk 2 | Wk 4 | Wk 6 | Wk 8 | Total change |

| Waist (narrowest point, cm/in) | | | | | | |
| Hips (widest point) | | | | | | |
| Chest/bust | | | | | | |
| Right thigh (midpoint) | | | | | | |
| Right upper arm | | | | | | |

> **Why measurements matter:** When strength training, you can lose fat and gain muscle at the same time — the scale stalls while your waist shrinks. Measurements catch what the scale misses.

## Daily Habit Checklist

*Copy one block per day. Aim for consistency, not perfection — 80%+ checked is a great week.*

```
Date: ________    Week #: ___

[ ] Water: 2–2.5 L
[ ] Veggies at lunch AND dinner
[ ] Protein at every meal (wk 2+)
[ ] No sugary drinks (wk 2+)
[ ] Steps target hit (7,000 wk 2+)
[ ] Workout completed (Mon / Wed / Fri)
[ ] In bed by ____ (sleep 7–8 hrs)
[ ] Food logged honestly

Today's win: _________________________________
Tomorrow's focus: ____________________________
```
